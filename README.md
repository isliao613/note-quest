# 🎹 NoteQuest 音符探險

給**小朋友**和**大人**的鋼琴教學 App。純網頁、零依賴、可離線使用，
用滑鼠、觸控、電腦鍵盤都能彈，接上 MIDI 電鋼琴也能直接上課。

**▶️ 線上試玩：<https://isliao613.github.io/note-quest/>**

---

## 快速開始

### 方式一：線上打開

直接連 <https://isliao613.github.io/note-quest/>，手機、平板、電腦都可以。
在 iPad 上用 Safari 開啟後選「加入主畫面」，用起來就跟一般 App 一樣。

### 方式二：離線單檔

下載 **`notequest.html`** 用瀏覽器打開，不需要網路也不需要安裝任何東西。

### 方式三：從原始碼執行

原始碼用了 ES modules，`file://` 會被瀏覽器擋住，需要一個本機伺服器：

```bash
python3 -m http.server 8000
# 然後打開 http://localhost:8000
```

修改原始碼後，重新產生單檔版：

```bash
node tools/build.mjs      # 產出 notequest.html
```

## 主要功能

**🎹 一台隨時都在的鋼琴**
螢幕鍵盤支援滑鼠、多點觸控與滑音；聲音是用 Web Audio 即時合成的鋼琴音色
（含琴槌雜訊與空間殘響），不需要下載任何音檔。

**📚 53 堂循序漸進的課程**
分成兩條路線各 7 個單元，前一課過關才會解鎖下一課。課程型態包括：

- 🎯 **認鍵** — 說出音名，在鍵盤上找到它
- 🪜 **跟彈** — 五指練習、音階（含拇指穿越指法）、和弦進行
- 📖 **視奏** — 看五線譜彈出對應的鍵（高音／低音／大譜表）
- 🥁 **節奏** — 跟著節拍器打出節奏型
- 👂 **聽力** — 音高高低、聽音找鍵、音程、和弦性質
- 💡 **樂理** — 概念卡加上小測驗，答錯會解釋為什麼
- 🎵 **曲目** — 把學到的東西放進真正的音樂裡

**🎼 落下音符 + 等待模式**
音符從上方落到對應的琴鍵上。開啟「等待模式」時，曲子會停下來等你彈對才繼續，
並顯示下一個音的唱名、指法與歌詞——這是初學者最好用的練習方式。
關掉等待模式就變成即時判定，會依照時間準確度給分與連擊。

**🎚️ 練得動的設計**
速度 40%～130% 無段調整、單手／雙手切換（練右手時左手伴奏會自動播放）、
節拍器、五線譜開關、示範播放。

**🎛️ MIDI 電鋼琴**
接上 USB MIDI 鍵盤即可使用，支援力度感應與延音踏板（CC64）。
需要 Chrome 或 Edge。

**✍️ 自訂曲目**
內建曲庫只收公有領域作品，但你可以把任何想彈的旋律自己打進去。
用**簡譜**（`5 3 3 - | 4 2 2 -`）或**音名**（`C4 E4 G4`）輸入，
邊打邊即時產生五線譜，存檔後就能用落下音符和等待模式練習。
可以匯出成 JSON 備份或分享給別人。

**🏅 進度追蹤**
等級與經驗值、每課星星、連續練習天數、9 種收集貼紙，全部存在瀏覽器本機。

## 操作方式

**電腦鍵盤**

```
白鍵   A  S  D  F  G  H  J  K  L  ;
黑鍵     W  E     T  Y  U     O  P
```

- `←` `→`：移動八度
- `空白鍵`：延音踏板

**觸控 / 滑鼠**：按住可以滑音；按琴鍵的位置越靠下緣，力度越大。

## 自己輸入曲子

到「曲目 → ＋ 新增自己的曲子」，用下面的寫法打上旋律即可。

| 寫法 | 意思 |
|---|---|
| `1 2 3 4 5 6 7` | Do Re Mi Fa Sol La Si（依選定的調） |
| `0` | 休止符 |
| `-` | 延長一拍，`1 - - -` 就是四拍 |
| `1_` | 半拍（八分音符），`1__` 是四分之一拍 |
| `1.` | 附點，時值 ×1.5 |
| `1'` / `1,` | 高八度 / 低八度，可疊加 |
| `#4` / `b7` | 升 / 降記號 |
| `\|` | 小節線，只是方便閱讀 |
| `C4 F#3 Bb5` | 也可以直接寫音名，和簡譜混用沒問題 |

例（小蜜蜂）：

```
右手  5 3 3 - | 4 2 2 - | 1 2 3 4 | 5 5 5 -
左手  1, - - - | 5, - - - | 1, - - - | 1, - - -
```

左右手拍數對不上時會自動補休止符，並在狀態列提醒你。

## 部署到 GitHub Pages

推上 `main` 時，`.github/workflows/pages.yml` 會自動把 `index.html`、`notequest.html`
與 `css/`、`js/` 發佈到 GitHub Pages。

**第一次需要手動開啟一次 Pages**（只做一次）：

1. 到 repo 的 **Settings → Pages**
2. **Source** 選擇 **GitHub Actions**
3. 回到 **Actions** 分頁，把失敗的那次 workflow 重跑（Re-run all jobs）

> 為什麼不能全自動？建立 Pages 站台的 API 需要 repo admin 權限，
> workflow 的 `GITHUB_TOKEN` 拿不到，所以 `actions/configure-pages` 的
> `enablement: true` 會失敗在 `Resource not accessible by integration`。
> 站台開好之後，之後每次推 `main` 都會自動部署，不用再手動處理。

如果不想用 Actions，也可以改成 **Settings → Pages → Source → Deploy from a branch**，
選 `main` / `/ (root)`。網站檔案本來就放在 repo 根目錄，`.nojekyll` 也已經包含在內，
這樣就完全不需要這個 workflow（記得把 `pages.yml` 刪掉，否則每次推 `main` 都會失敗）。
